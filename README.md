The Python analysis (analysis/analysis.py) loads the experiment results from data/results.csv and produces four charts. Chart 1 shows the average execution time per experiment. Chart 2 shows all individual runs as a box-and-strip plot, confirming the results are consistent. Chart 3 isolates the speedup ratio between each cache-friendly/unfriendly pair. Chart 4 applies the hit ratio formula T_avg = T₁ + (1−H)×T₂ from Stallings Chapter 3 (Lecture 02) to back-calculate the implied cache hit rate H for each experiment — connecting the measured hardware behaviour to theoretical computer architecture.
